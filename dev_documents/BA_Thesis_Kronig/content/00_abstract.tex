\textbf{Abstract:} \hspace{0.3cm} The OWASP Mobile Application Security (MAS) project is the industry standard for Android mobile application security. It comprises all aspects of mobile application security, from documenting weaknesses to providing verification standards. Part of it is the Mobile Application Security Testing Guide (MASTG), which provides detailed instructions on how to thoroughly test mobile applications. The MASTG is complemented with a catalog of reference apps. These apps serve as educational resources by including intentionally built-in weaknesses that can be found using the MASTG. They can be used for benchmarking both static and dynamic application security testing tools. However, many of the existing reference apps are limited in scope and have become outdated due to a lack of maintenance. We evaluated the state of the art of the MASTG reference apps. We found that only about a third of the vulnerabilities documented by OWASP MAS are represented in the MASTG reference apps we analyzed. The ten most frequently implemented vulnerability types account for half of all implemented vulnerabilities. Based on the findings, we developed three open-source MASTG reference apps containing 28 vulnerabilities of both static and dynamic nature. Each implemented vulnerability is mapped to its OWASP counterpart and contains detailed documentation on where it can be found. We focused on vulnerabilities that received no coverage in existing reference apps. Our apps have increased the coverage of vulnerability types by 42\%. The MASTG reference apps we developed can be used both as an educational resource and for benchmarking security testing tools.
