\section{OWASP MAS}

The OWASP Mobile Application Security (MAS) project aims to represent the industry standard for mobile application security. It comprises three main sub-projects. The OWASP Mobile Application Security Verification Standard (MASVS) defines the security measures a mobile app should have, and provides mobile developers  with a security standard to adhere to for security best practices. The OWASP Mobile Application Security Weakness Enumeration (MASWE) lists and discusses a large range of mobile security vulnerabilities, including how they can be introduced and how they can be avoided. The OWASP Mobile Application Security Testing Guide (MASTG) is an industry standard manual for testing and evaluating the security of mobile apps. The MASVS lays out the requirements a mobile app has to fulfill for industry-level security practices, the MASTG defines how these requirements can be tested, and the MASWE describes the vulnerabilities found through this testing process. 

A part of the MASTG is a dataset of intentionally vulnerable applications that are hosted by OWASP MAS \cite{owasp_reference_app_website}. These apps serve as educational reference material for the MASTG.
