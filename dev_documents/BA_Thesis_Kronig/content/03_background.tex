\section{OWASP MAS}

One such dataset of intentionally vulnerable apps is hosted by OWASP Mobile Application Security Testing Guide (MASTG) \cite{owasp_reference_app_website}. The OWASP MASTG is an industry standard manual for testing and evaluating the security of mobile applications. As part of the OWASP Mobile Application Security (MAS) project, it contains a set of intentionally vulnerable apps that serve as educational reference material for the MASTG. The vulnerabilities that the MASTG is designed for are laid out in the OWASP Mobile Application Security Weakness Enumeration (MASWE).
